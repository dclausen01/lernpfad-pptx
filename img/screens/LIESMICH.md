# Screenshots

Hier eigene Screenshots ablegen. Der Dateiname muss genau dem Namen entsprechen, der im Lernpfad im gestrichelten Platzhalter („📷 Screenshot folgt“) angezeigt wird, z. B. `ppt-e1-oberflaeche.png`.

Namensschema: `{ppt|oo}-{modul}-{thema}.png`

Eine Liste aller vorgesehenen Screenshots und eine kurze Anleitung stehen in `lehrkraefte.html`, Abschnitt 4.
